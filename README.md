# 💳 Credit Card Default Prediction

A Machine Learning project that predicts whether a customer is likely to default on their credit card payment based on historical financial and demographic data.

This project demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), model training, evaluation, and prediction.

---

## 📌 Project Overview

Financial institutions face significant risks due to customer loan and credit defaults. This project aims to build a predictive model that helps identify customers who are likely to default on their next payment.

The model can assist banks and financial organizations in making informed credit decisions and reducing financial risk.
